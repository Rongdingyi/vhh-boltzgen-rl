## 结论（proposal §12 实验二）

- 两种"纯加权"方法（current_cf、sign_only）的 **局部偏好符号正确率只有 ~0.2–0.3**，
  即使它们使用了完全相同的查询数据——单向/非负权重无法表达背景翻转。
- **signed 局部比较**把符号正确率提高到 ~0.62，并显著降低序列边缘 KL。
- **v2（signed + 同结果边）**在不牺牲序列 KL 的前提下，把条件几何 KL 从
  signed 的 0.129 压到 **0.0005**：同序列不同构象边确实约束了"奖励没有要求的
  额外几何扭曲"（proposal §5/§8）。
- oracle（直接拟合精确 Gibbs 目标）接近 0，确认评估口径正确。
- 未验证：真实 BoltzGen 代理下这些结论是否成立（Exp3/Exp4 进行中）。

## 结论（修正版，审阅错误 E4 修复后重跑）

- 修正后，两种加权方法（current_cf / sign_only）并非原先报告的"符号正确率 0.2"：
  它们分别达到 **0.816 / 0.800** 的局部符号正确率，但**序列边缘 KL 高**（0.53 / 0.57）。
- **signed 局部比较**在精确模型下把序列 KL 压到 **0.0007**（符号正确率 0.994），
  **v2（+同结果边）** 为 0.0005 且条件几何 KL 为 **0.0000**（signed 为 0.0042）。
- 因此 exact-model 层面的结论是：
  - "有向局部比较"优于"单一非负权重"（存在明显差距，但不是原来那种压倒性的 0.2）；
  - 同结果边在精确模型中几乎不损失序列 KL，并进一步约束条件几何分布；
  - 先前 "weighted 0.18–0.20" 的数字是 E4（z 方向写反 + drop 边符号）的产物，已作废。
